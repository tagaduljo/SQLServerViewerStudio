SQL Server Viewer Studio — Privacy Policy
Publisher: Blue Works Labs
Contact: blueworkstech@outlook.com
Effective date: October 28, 2026

What the application does
SQL Server Viewer Studio is a desktop database viewer. You choose a SQL Server and authentication method. The application connects directly to that server to read the database catalog, object definitions, descriptions, and records you request. Database results may contain personal or confidential information depending on the server and your permissions. Connect only to servers and data you are authorized to access.

Connections and credentials
For Windows Authentication, Windows supplies your current account's authentication to the selected server. For SQL Server Authentication, the username and password you enter are used to authenticate directly to that server. SQL usernames and passwords are not saved to configuration files. They are held in process memory for the connection session. Connection pooling is disabled. The password entry is cleared after connecting and when the login window closes.

Encryption is enabled and certificate validation is required by default. Changing Encrypt connection or Trust server certificate changes the protection of communications with your selected server. Your database administrator controls the server's authentication, access permissions, encryption support, auditing, and retention of server logs.

Local information and preferences
The application reads local SQL Server instance names from Windows registry entries to populate the server selector. It reads the Windows app color preference when Use Windows setting is selected. It does not broadcast discovery requests across your network.

The saved connection preferences contain the server name, authentication method, encryption and certificate-trust choices, record limit, and default object views. Color theme and layout density are also saved. The Microsoft Store edition stores these preferences in its private per-user application data. The unpackaged desktop edition stores connection and browsing preferences under C:\ProgramData\Blue Works Labs\SQL Server Viewer Studio\server.json and appearance preferences under your local application-data folder. Shared desktop preferences may be readable by other users who have access to that folder. Demo browsing preferences are stored separately and do not replace your real server selection.

Database results and definitions are displayed in memory and are not automatically exported, uploaded, or written to application logs. If you explicitly copy a value, grid selection, or SQL definition, it is placed on the Windows clipboard. Clipboard history, synchronization, other applications, and any files you create after copying are controlled by you and Windows.

Data sharing and collection
Blue Works Labs does not operate a backend for this application and the application does not send database contents, credentials, telemetry, analytics, or advertising identifiers to Blue Works Labs. There are no advertisements or tracking SDKs. Data is transmitted only to the SQL Server you select as needed to perform your requested connection and reads. Your server may use its own infrastructure and logging. The offline demo uses fictional data bundled with the application and makes no database connection.

The Microsoft Store, Windows, and your SQL Server may independently collect installation, diagnostic, account, or operational information under their own settings and privacy policies. If you choose Email support, your configured mail application opens. Any message or attachments you send are shared with Blue Works Labs through your email provider and are used to respond to your request. Do not send database passwords or confidential records. You can request access to or deletion of support correspondence by contacting blueworkstech@outlook.com; legally required records may need to be retained.

Your controls and retention
You choose which server to connect to and which objects and records to inspect. Close the application to end its active session. You can change the remembered preferences in the login and Settings windows. Close the application and remove its preference files to reset them; the About window shows the current settings directory. Windows removes private package data when the Store application is uninstalled, subject to Windows management and backup settings. Unpackaged shared preferences remain until you or your administrator remove them. Your database administrator controls deletion and access to the actual database records; this viewer does not edit or delete them.

Children
This application is a database administration and development tool. It is not directed to children and does not require a Blue Works Labs account.

Changes and questions
This policy is updated when the application's data handling changes. The current policy is included in About & privacy. Contact Blue Works Labs at blueworkstech@outlook.com with privacy or support questions.
